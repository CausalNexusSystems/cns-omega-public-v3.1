WHAT THIS PHASE TESTS
The legitimate binary is hashed; a 'bribe' flips one byte of a copy. The
tampered binary must be detectable by hash, and the build must be bit-
reproducible from source.

RESULTS
  Bribed binary detectable : True
  Build bit-reproducible   : True
  Verdict                  : PHASE5_PASS

WHY THIS RESULT
Any single-byte change to the binary changes its SHA-256, so a supply-chain swap
is caught by the seal. Recompiling from source yielded a bit-identical binary,
so an auditor can independently reproduce and verify the exact build.
