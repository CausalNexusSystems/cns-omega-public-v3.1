WHAT THIS PHASE TESTS
Using a TEST-ONLY harness build (cryptographically distinct from production),
redundant decision units are corrupted per-node. Single checks, naive attacks,
and fully-coherent attacks are measured to find the real capture threshold.

RESULTS
  Each single check forces safe state : True
  Naive attack defeated (all fractions): True
  Coherent tolerance                  : 50%
  Coherent capture threshold          : 75%
  Classical BFT bound (reference)     : 33%
  Verdict                             : PHASE6B_DEPTH_PASS_WITH_DECLARED_LIMIT

WHY THIS RESULT
Every single-check corruption forces a safe state, and naive attacks fail at all
fractions. A fully-coherent attacker is tolerated up to 50% and captures the
decision at 75% - ABOVE the classical byzantine bound of 33%. The limit is
declared openly, not hidden.

HONEST BOUNDARY
Measured with a test-only harness; the production binary does NOT contain the
harness. This measures consensus tolerance, not a claim of invulnerability.
